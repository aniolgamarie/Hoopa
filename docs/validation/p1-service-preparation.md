## 有界 Unix 收发

实现位于 [wire_linux.go](../../internal/service/wire_linux.go)，遵循
[传输契约](../../specs/001-hoopa-proxy-manager/contracts/service-transport-v1.md)。
它接受调用方已认证的 Unix 连接，每连接一次请求/响应；四字节大端长度、有限正文和
EOF 构成一帧。请求上限 128 KiB、响应 64 KiB，每调用最多 15 秒或更早的 context
deadline。取消会中断阻塞读写，并等待取消回调结束，避免函数返回后继续关闭连接。

严格解析拒绝重复 key、非法 Unicode、尾随 JSON、超长原始正文和错误信封；响应
request_id 必须匹配请求。合法空白/key 顺序保留原字节，便于重放持久 Result。
无效本地输入在写帧和 CloseWrite 前拒绝。该层只校验信封，不声称已验证所有业务
params/data，也不执行认证、重试、存储或核心操作。

两批 race 检查分列：

| 检查 | 结果 |
| --- | --- |
| `wire-01` 全组 | 11 顶层、36 子测试，共 47 pass，0 fail/skip；真实 Unix socketpair，涵盖帧/EOF、大小、严格信封、ID 与阻塞写取消 |
| `wire-02` 受影响复验 | 5 顶层、17 子测试，共 22 pass，0 fail/skip；补实际部分正文已被读取后的取消、早期拒绝未发字节/未半关闭、成功后 FD 仍可用 |
| 静态及格式 | 两批 vet 退出 0；两个 Go 文件格式/空白检查通过；生产实现两批之间未变 |

第二批新增一个顶层测试；当前测试树为 12 顶层/36 子测试，没有一次最终全树运行
的声明，也不把两批重叠节点相加。部分读取消用不消费字节的 MSG_PEEK 观察原前缀
已被读者取走后再取消；没有把预先取消的 context 当作阻塞读中断证据。

独立稳定代码审查未发现 wire 层阻断。执行回执固定了源码和 API Schema；传输契约
是在测试期间另行写出的规则文档，独立审查核对二者一致，不追改原执行输入清单。
这些 socketpair 测试不代表服务发现、peer 认证或核心生命周期已经验收。

## Cobra 固定依赖

在独立临时 module/cache 中，从官方 Go 模块源取得 Cobra v1.10.2；TLS 与
sum.golang.org 校验保持启用。选定 pflag v1.0.9、mousetrap v1.1.0；完整图七个模块
的下载元数据、模块摘要和许可证原件分别保存。Linux 样例实际链接 Cobra/pflag，
不把文档/上游测试依赖冒称产品必需运行模块。

离线 `go mod verify` 和构建通过；独立参数解析样例 race 为 1 顶层/3 子测试通过，
正常调用退出 0、非法参数退出 2。287 个模块源文件摘要已复核。最初 VCS 状态检查
失败和封存工具的 Python 3.8 兼容错误保留；后者没有改变依赖输入。

根 `go.mod` 尚未添加依赖；实际 CLI 开始使用后才纳入经验证的 require/go.sum。
仓库继续保存代码与文本摘要，下载的依赖缓存、编译产物及私有日志不入 Git。
