# US4 应用入口与 Plan 输入

2026-10-29，T048 的核心资格、批准注册表、私有绑定、纯编译及 Plan 接线分别验证。输入验证索引（本地原件 `../../experiments/gost-mihomo/us4-app-input-validation.json`，不随Git上传）记录每批范围、固定输入和原始收据。当前 control 接线最终独立复核通过，T048 按有限模块边界完成，累计62/140；T051 的产品双应用／回滚／管理器死亡矩阵尚未执行。

每个 managed、未计量应用有独立不可变绑定，包含应用 ID、完整入口及实际 SourceSettings 摘要。显式初始化只准备私有文件，不占端口、不创建操作、不启动核心。所有已保留绑定，包括候选未使用的绑定，都参与名称、端点和认证对冲突检查；历史 bundle 中的绑定与现存记录不一致时要求恢复，查询和 Plan 不生成替代凭据。

Plan 在协调器锁内读取并校验历史和现存记录，然后保留自己拥有的完整字节。应用编译独立核对记录、ID、父设置摘要和入口；生成身份包含 app compiler 版本、完整输入摘要和设置摘要。私有绑定作为 app_binding bundle 原件保存，公开 Plan 只含文件标识与 SHA。确认后 Apply 再次读取校验，绑定丢失或历史身份变化会在工作目录／操作／核心变更前拒绝。

应用命名入口按 ID 排序；shared 入口仍在前。app 条件只编译成原顺序中的 IN-NAME，不通过 listener proxy 增加优先级。一个配置至多三个 managed 应用入口；超出、计量或不支持的 process 谓词明确拒绝。bypass 仅作为后续子进程环境接入的配置元数据，本阶段没有实施 NO_PROXY。入口标签不证明原始 PID。
